# Aşama 2a — Rota üretici (Human beta rotası) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kanonik görev verisinden kural tabanlı bir rota üretici kurmak ve Human 1–30 rotasını beta eşiğinde uçtan uca üretmek (generate → overrides → validate → JSON + Lua dışa aktarım).

**Architecture:** `pipeline/generate/` dört saf modül içerir:
- görev seçimi ve bağımlılık grafiği (`graph.py`),
- hub kümeleme ve sıralama (`hubs.py`),
- XP tahmini (`xpsim.py`),
- adım üretimi (`steps.py`).

Bölgeler arası sıra elle yazılan `data/zone-order/<route>.yaml`'dan gelir. İnsan düzeltmeleri `data/overrides/<route>.yaml` yamalarıyla uygulanır. Çıktı Aşama 1'in `check_route` doğrulayıcısından geçer, sonra site için JSON'a, addon için Lua'ya aktarılır.

**Tech Stack:** Python 3.14, pytest, jsonschema, PyYAML (yeni bağımlılık yok).

**Spec:** `docs/plan.md` (§5.2, §6.2–6.4, §7, §8.1–8.2, Ek A Aşama 2). Aşama 1 sonucu: `main` @ ac73168.

**Kapsam notu:** Bu plan Ek A 2.2–2.8'i kapsar (2.1 Aşama 1'de yapıldı). Ek A 2.9 (kalan 9 rota) bu planın dışında, iki nedenle:
